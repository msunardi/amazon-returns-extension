Allow access to your Amazon orders?

To build this dashboard, the extension needs your permission to read your Amazon order history in this browser. Here is what it does:

  • It reads the Your Orders pages for the last 30 days, using the Amazon sign-in already in this browser.
  • It reads the return pages only in return windows you open from this dashboard, to save the QR code Amazon shows you.
  • Everything is stored only on this computer (in the extension's local storage). Nothing is sent anywhere else.
  • It only scans when you click a button. You can revoke access and delete the data at any time.

Chrome will ask you to confirm access to the Amazon site and Amazon's image servers.
